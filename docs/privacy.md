# 本地数据与 BYOK 隐私

v1 无账户、无账号系统、无云同步，也无产品遥测或分析。用户数据边界由浏览器、项目公共数据
Functions 和用户选择的 AI 提供方三部分组成。

## 当前设备保存什么

应用使用版本化 IndexedDB 保存：

- 自选股；
- 界面偏好；
- AI Base URL、模型和是否记住 key 的设置；
- 用户明确同意记住时的 API key；
- 完整研究报告或明确标记为未完成的草稿，以及生成时的有限上下文快照。

API key 默认只存在于当前会话。只有用户明确选择并同意“在此设备记住”后，它才进入
IndexedDB。浏览器存储不能抵御恶意扩展（extension）或受损（compromised）页面，因此不应在
不可信设备上启用记住功能。

## 数据不会去哪里

AI API key 和 AI 请求不会发送到本项目服务器，也不会进入 Tushare 请求、Vercel Functions、
项目日志或诊断输出。服务器端的 `TUSHARE_TOKEN`、`CRON_SECRET` 和 Blob 凭据不会进入浏览器。

应用的本地 JSON 导出中，结构化 provider 设置不包含 API key；导出会保留经过清洗的设置、
自选股、报告完整上下文和 AI 原文，但不包含 UI preferences。用户仍应把导出文件视为个人研究
资料。恶意提供方理论上可以在报告正文中自行回显敏感文本，导出或分享前应检查报告内容。

## 自定义 AI 提供方

点击生成报告后，浏览器把以下内容直接发送给用户选择的 OpenAI-compatible 端点：

- 用户 API key、模型标识和请求参数；
- 规范化市场/财务数据、确定性指标和数据截止日期；
- 可用性、缺失原因、来源和限制；
- 要求结构化输出和禁止投资建议的系统指令。

自定义端点会接收并看到这些内容。它可以按自己的隐私政策记录请求，本项目无法约束该行为；
用户必须只选择可信 HTTPS 服务，并自行理解其数据保留政策和费用。

为支持用户配置任意 HTTPS 端点，CSP 的 `connect-src` 范围比固定提供方更宽。这不允许远程
脚本或 HTML，但意味着受损页面代码可能尝试向 HTTPS origin 发送浏览器可访问的数据。完整
安全权衡见 [security-csp.md](security-csp.md)。

## 用户控制

“本地隐私”页面提供四类控制：

1. 导出本地数据 JSON，provider 设置字段不导出 API key；
2. 清除 AI 凭据，同时保留自选股和报告；
3. 删除单个已保存报告；
4. 确认后清除全部本地应用数据。

清除全部会删除应用的 IndexedDB 数据，但不会撤销 AI 提供方已经接收的请求，也不会删除用户
此前下载的导出文件。浏览器自身的站点数据清理也可删除本地数据库。

## 公共市场接口

浏览器会向本项目 Vercel Functions 请求股票代码、历史日线、概览、财务数据和市场状态。
接口执行基本 IP 级限流并记录不含 secret 的运行信息；v1 不建立用户身份，不保存用户自选股
或 AI 报告。市场数据来源为 Tushare Pro，口径为历史日线收盘，不是实时行情。

所有分析和报告仅供研究与教育使用，不构成投资建议、交易指令或收益保证。
